# Scripts

This directory contains all build scripts and other utility scripts.

## Utility Scripts

### `create_placeholders.py`

This script generates placeholder images for the game's characters and other assets. It's used to create simple, colored squares as temporary visuals.

To run it, execute the following command from the root directory:
```sh
python3 scripts/create_placeholders.py
```
