# Diablo-like Game

This project is a top-down, action RPG in the vein of the Diablo series.

## Features

*   **Character Classes:** Multiple character classes with unique abilities.
*   **Randomized Loot:** A deep and engaging loot system with procedurally generated items.
*   **Dungeon Crawling:** Explore vast, procedurally generated dungeons.
*   **Combat:** Fast-paced, satisfying combat with a variety of monsters.

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

You will need to have Python 3 and pip installed on your system.

### Installation

1.  Clone the repo:
    ```sh
    git clone https://github.com/your_username/your_repository.git
    ```
2.  Navigate to the project directory:
    ```sh
    cd your_repository
    ```
3.  Install the required packages:
    ```sh
    pip install -r requirements.txt
    ```

### Running the Game

To run the game, execute the following command from the root directory:

```sh
python3 src/main.py
```
